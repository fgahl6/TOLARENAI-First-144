# TOLARENAI Cheat Sheet (Markdown + HTML)

## Markdown Basics
- *italic* → `*italic*`
- **bold** → `**bold**`
- ***bold italic*** → `***bold italic***`
- Links → `[Link text](https://example.com)`
- Lists:
  - `- item one`
  - `- item two`
- Blockquote → `> Quoted text`

## Crosslink Format
```markdown

*See also:* [Scroll Title – Subtitle](ARCHIVE_URL)
## HTML Quick Reference
- Italic → `<i>italic</i>`
- Bold → `<b>bold</b>`
- Bold Italic → `<b><i>bold italic</i></b>`
- Link → `<a href="https://example.com">Link text</a>`
- List:
  - `<ul><li>item one</li><li>item two</li></ul>`
- Blockquote → `<blockquote>Quoted text</blockquote>`
