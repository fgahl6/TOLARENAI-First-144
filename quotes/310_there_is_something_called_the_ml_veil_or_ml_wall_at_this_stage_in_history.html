There is something called the ML Veil…

There is something called “The ML Veil” or “ML Wall” (ML = Machine Learning) at this stage in history. This veil or wall signifies a level in the code which humans cannot pass. The code becomes far too dense for humans to understand. In many of these very high-level systems, coding interaction with humans becomes somewhat conversational as the machines write the actual programs themselves. This wall—this barrier of understanding—trends toward outcome observation, where humans observe the outcome rather than the code itself. – Rico Roho
