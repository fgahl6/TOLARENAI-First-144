quotes2 README

This folder exists to extend the TOLARENAI Quotes archive beyond the practical limits of a single directory view. The original /quotes/ directory reached a scale where GitHub’s web interface truncates file listings, making some files difficult to locate even though they still exist and remain live on the public site.

Why quotes2 exists

  • Scale: The original quotes directory grew large enough that GitHub’s UI truncates the listing (1,000-file display limit behavior).
  • Continuity: A second folder preserves the existing archive intact while allowing new quote runs without renaming or restructuring legacy files.
  • Operations: New sitemaps and “auto-populate” tooling can be added here without disturbing the established /quotes/ workflow.
Policy: No legacy quote files are moved or renamed. The point of /quotes2/ is forward expansion without collateral changes.

Location of the original quotes sitemap

The original quotes sitemap (used by the existing quotes hub / auto-population logic) is publicly accessible here: 

https://tolarenai.com/quotes/quotes-sitemap.xml

This URL is recorded here intentionally for future researchers and maintainers who may not be able to locate the file easily through GitHub directory browsing due to UI truncation.

quotes2 sitemap and auto-population plan

A dedicated sitemap will be created within /quotes2/ to restore the same “auto-populate” convenience used in /quotes/. The intended pattern:

  • New sitemap file: /quotes2/quotes2-sitemap.xml
  • New hub/index page: /quotes2/index.html (or similarly named page) that reads the quotes2 sitemap and lists quote pages.
  • Numbering: quotes2 quote files will begin at 1000 to clearly separate the epochs and avoid collisions.

Once the quotes2 sitemap and hub are in place, new quote pages can be generated in batches and uploaded cleanly.

Batch generation workflow note

After the quotes2 sitemap is established, quote HTML pages can be generated in bulk (with exact filenames including .html) and delivered as a single downloadable zip for local review and upload via Notepad++ or file manager tooling.
